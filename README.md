# Кино на вечер

Прототип веб-сервиса, который помогает выбрать фильм на сегодняшний вечер: каталог для знакомства с фильмами и страница выбранного фильма.

**Идея:** найти фильм, который подходит именно этому вечеру — времени, силам и настроению, — и понять, *почему* он подходит.

- Опишите вечер одним предложением («Сегодня у меня около двух часов, сил почти не осталось, хочется тепла») или своими словами — подборка перестроится и объяснит каждый выбор.
- Возьмите до трёх «билетов на сегодня», сравните два фильма, доверьте выбор случаю или решите вместе — честно, с голосованием и вето.
- Вы сидите в тёмном зале: проектор за спиной, его свет принимает цвета фильма, на который вы смотрите. Откройте фильм — его кадры заполнят экран: ощущение, нагрузка, сюжет с регулируемым уровнем спойлеров, деликатные моменты, Подсказчик, оценки, источники.

Подробно: [docs/product.md](docs/product.md) · исследование: [research.md](research.md)

## Запуск

```bash
npm install
npm run dev
```

## Сборка и публикация

```bash
npm run build   # статический сайт в dist/
```

Публикация на GitHub Pages — автоматически из ветки `main` (`.github/workflows/deploy.yml`). В настройках репозитория: *Settings → Pages → Source: GitHub Actions*.

Стек: Vite, React, TypeScript, Motion, Zustand, WebGL (свет проектора и кресла). Данные о фильмах — `movies-data/`; кадры — The Movie Database (TMDB), отобраны без спойлеров, источник каждого — в `movies-data/stills.json`.

Дизайн-система: [DESIGN.md](DESIGN.md).
